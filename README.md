# Portfólio — João Henrique Flauzino

Site estático do meu portfólio profissional: software, machine learning e
automação. Publicado via GitHub Pages.

- **Conteúdo:** quatro cases (previsão de vento com redes neurais — projeto
  STEAM, Tech4Humans, File Sorter AI, ATLAS), seção de projetos em equipe,
  método de desenvolvimento agêntico, trajetória e currículos em PDF
  (PT-BR e EN, com fontes LaTeX).
- **Estrutura:** `index.html` (página única, fontes embutidas),
  `cv/` (PDFs + fontes LaTeX), `assets/`.
- **Sem cookies, analytics ou requisições externas** — HTML + CSS puro,
  sem dependência de JavaScript para navegação ou conteúdo.
- **Atualizar:** editar `index.html` ou os arquivos de `cv/` e fazer push em
  `main`; o Pages publica automaticamente.
